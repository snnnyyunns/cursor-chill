### How to share (no terminal)

A GitHub repository is one shared folder on the internet.

1. One person goes to github.com, signs in, clicks **New repository**. Empty is fine.
2. That person opens **Settings → Collaborators** and invites the others by their GitHub username or email.
3. Everyone else installs **GitHub Desktop**, clicks **Clone**, and picks that repository.
4. In Cursor: **File → Open Folder** and choose the folder GitHub Desktop just created.
5. To share work: in GitHub Desktop, write a short note, click **Commit**, then **Push**.
6. Before you start a new piece: in GitHub Desktop, click **Fetch** / **Pull**.

Solo: skip the invite. Still use GitHub Desktop so you have a backup.

If something asks for a password, use a GitHub sign-in in the browser. Do not paste keys into chat.
